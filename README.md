# CampusPool

Verified-student carpool matching platform for daily college commutes.

## Overview

Students commuting to college from the same area typically travel alone in separate cabs, which is costly and can be unsafe during early morning or late evening hours. CampusPool addresses this by connecting students traveling similar routes at similar times, enabling shared, cost-split rides.

## Core Features

- **Trip posting** — Students specify their starting location and departure time.
- **Intelligent matching** — A scoring algorithm ranks candidate matches based on route and time proximity.
- **Verified access** — Registration is restricted to users with a valid college email address.
